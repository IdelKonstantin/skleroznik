0. POSIX IPC (Очереди сообщений)

Важные моменты про POSIX очереди сообщений:
1. Имена очередей: Должны начинаться с / (например, /myqueue) .

2. Персистентность: Очереди живут в ядре и переживают завершение процессов. Их нужно явно удалять через mq_unlink() .

3. Ограничения:

	- Максимальное количество сообщений (mq_maxmsg)

	- Максимальный размер сообщения (mq_msgsize)
	Эти параметры задаются при создании и могут иметь системные лимиты:

	cat /proc/sys/fs/mqueue/msg_max      # макс. сообщений в очереди (по умолч. 10)
	cat /proc/sys/fs/mqueue/msgsize_max  # макс. размер сообщения (по умолч. 8192)

4. Приоритеты: Сообщения с более высоким приоритетом всегда извлекаются раньше. При одинаковом приоритете — FIFO .

5. Блокировки:

	- mq_send блокируется, если очередь заполнена

	- mq_receive блокируется, если очередь пуста

	Можно использовать O_NONBLOCK для неблокирующих операций

6. Уведомления: POSIX очереди поддерживают асинхронные уведомления (mq_notify), когда процесс может получить сигнал при появлении сообщения .

	Проверка состояния очереди из командной строки в bash:
	
	# Смотрим все очереди POSIX в системе
	ls -la /dev/mqueue/ (здесь появится очередь с нашим названием)
