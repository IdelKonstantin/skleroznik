0. Сигналы

1. Async-signal-safe функции: В обработчиках сигналов можно вызывать только ограниченный набор функций (см. man 7 signal-safety). printf небезопасен, write — безопасен.

2. Сигналы не ставятся в очередь: Обычные сигналы (1-31) не ставятся в очередь. Если процесс уже имеет ожидающий сигнал того же типа, новый может быть потерян.

3. Сигналы реального времени (32-64): Ставятся в очередь и могут нести данные.

4. Нельзя перехватить: SIGKILL и SIGSTOP нельзя перехватить, игнорировать или заблокировать.

5. Маскирование: sigprocmask позволяет временно блокировать доставку сигналов.

6. signalfd: Современный способ интегрировать сигналы в цикл с select/poll/epoll.

Примеры отправки сигналов процессу в bash:

# Отправить сигнал процессу
kill -SIGUSR1 1234
kill -USR1 1234

# Посмотреть все сигналы
kill -l

# Отправить сигнал с данными (через bash)
kill -n SIGRTMIN 1234

# Посмотреть, какие сигналы игнорирует процесс
cat /proc/1234/status | grep -i sig
